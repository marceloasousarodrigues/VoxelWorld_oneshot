# Archived Ursina implementation

This is the deprecated Python + Ursina implementation preserved from the M34 source
revision. Godot in [`../../godot/`](../../godot/) is the canonical, active game project.

The archive retains the former Python runtime modules, Python tests and development
scripts, `requirements.txt`, `pytest.ini`, the former world configuration, and the
original `voxel_textures/` collection. Use it for historical reference only; new game
development and validation belong in the Godot project.
