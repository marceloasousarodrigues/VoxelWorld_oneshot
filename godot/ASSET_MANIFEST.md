# M17 Godot — Asset Manifest

Every external resource used by the Godot project under `godot/`, with
its source, licence and local destination.

## Status

**No external asset is shipped or loaded by the project.** Every texture is a
copy of a texture that already exists inside this repository and is already used
by the production Ursina game (M12/M14 texture integration), so the Godot port
adds no new third-party dependency and no new licence obligation. Review-only
downloads (the M41c Kenney Voxel Kit inspection copy) stayed in the local
temporary directory and are not part of the repository or runtime.  The 2026-10-19 crafting
increment added the pack's furnace faces and 26 item icons (materials, food and
tools) from the same in-repo `MINETEST_TEXTURES` directory; 85 keys are vendored
now. The M18 visual pass added six *derived* textures (not external downloads):
`crafting_table_top`, `crafting_table_side`, `furnace_opening`, `glass_clean`,
`oak_leaves_clean` and `pine_leaves_clean`. They are generated from the same
Minetest art by `godot/tools/generate_m18_textures.py` and keep the
CC BY-SA 3.0 attribution; `glass_clean` is fully procedural. The M21 pass added
twelve **fully procedural** textures (no third-party source): farmland top/side,
four wheat growth stages and six animal/farming item icons
(`item_raw_meat`, `item_cooked_meat`, `item_hide`, `item_bone`,
`item_wheat_seeds`, `item_bone_meal`), generated by
`godot/tools/generate_m21_textures.py`. The M22 visual pass added
**twenty fully procedural** textures (no third-party source): birch bark/leaves,
blossom leaves, bush, three wildflowers, timber frame, terracotta roof tile,
ridge and eave faces, packed path top/side, lantern side/top, fence rails,
barrel side/top and a plank door, generated by
`godot/tools/generate_m22_textures.py`. The M29 medieval pass
added **fourteen fully procedural** textures (no third-party source): warm
plaster, dark structural timber, coursed stone wall, a braced plaster panel,
slate tile/ridge/edge, a framed window, a louvered shutter, chimney side/top,
a ridge finial, a flower-box planter and its bloom cutout, generated by
`godot/tools/generate_m29_textures.py`. The M18 runtime grading in
`TextureLibrary` (brightness/contrast/saturation and channel tints) is applied in
memory only — the vendored PNGs on disk are unchanged.

## Textures (block atlas + item icons)

- **Package**: Minetest `default` game texture pack (the subset vendored by this
  repository).
- **Original source**: <https://github.com/minetest/minetest_game> (`mods/default/textures`).
- **Licence**: CC BY-SA 3.0 (per the `default` game's bundled licence). Attribution:
  © the Minetest `default` game contributors. Redistribution under the same licence
  is permitted; the copies here are unmodified.
- **In-repo source path**: `archive/ursina/voxel_textures/MINETEST_TEXTURES/` (38 keys) plus two
  files under `archive/ursina/voxel_textures/blocks/`:
  - `grass_side_composite.png` — a Minetest-derivative composite already used by
    M12;
  - `water.png` — a small placeholder tile present in the repository since M9.
- **Local destination**: `godot/assets/textures/` (the PNG files
  are copied verbatim, no rescaling; `bedrock`/`obsidian` reuse the same
  `default_obsidian_block.png`, and `item_iron_*` reuse the pack's "steel" art
  because Minetest draws its iron tier as steel).
- **Provenance record**: `godot/assets/texture_sources.json` is
  generated by `godot/tools/import_textures.py` and lists, for every
  texture key: block description, source path inside the repository, licence note,
  destination file name and pixel size. Regenerate with:

  ```powershell
  python godot/tools/import_textures.py
  ```

- **Consumption**: at runtime `TextureLibrary` (`scripts/core/texture_library.gd`)
  packs the PNGs into a single `Texture2DArray` (one layer per named face texture)
  which every chunk material samples as `atlas`. The animated water atlas layers
  come from `default_water_source_animated.png` (8 frames, 16 px each); `water.png`
  is the static fallback used when the animated sheet is missing.  The item icons
  ride along in the same array: they are never sampled by the voxel shaders, only
  turned into HUD textures by `TextureLibrary.icon(key)` through
  `ItemDB.icon_key(item_id)`.
- The import script also defines a CC0 (ambientCG) licence note for M11 sources, but
  no texture in the current manifest actually uses it — the Godot project ships only
  Minetest-derived tiles.

## M41b external review (not integrated)

The M41b visual review inspected preview art from Quaternius, Kenney, KayKit and
the Phantom Camera documentation. No model, texture, animation or plugin from
those sources is loaded by the game. The preview images under
`prototypes/m17/results/godot/m41b-asset-previews/` are review evidence only and
are not shipped assets. The full assessment is
`prototypes/m17/results/godot/m41b-external-asset-review.md`.

## M41c external review (not integrated)

The M41c hand/tool pass rechecked the candidate 3D packs and retained the
in-house procedural models:

- **Quaternius Cube World Kit** — <https://quaternius.com/packs/cubeworldkit.html>,
  CC0 1.0, 108 models in FBX/OBJ/Blend/glTF. The official preview was inspected;
  the tools are simpler flat props than the target. Not imported.
- **Kenney Voxel Kit** — <https://kenney.nl/assets/voxel-kit>, CC0 1.0, 48 files.
  The archive was downloaded to `%TEMP%\m41c-assets\` outside the repository and
  extracted for inspection. It contains 47 `block N` cube meshes plus a base
  block and no tools, hands or weapons. Not usable for held items.
- **Kenney Voxel Pack** — <https://kenney.nl/assets/voxel-pack>, CC0 1.0, 2D
  128 x 128 tiles. It is a 2D icon pack, not a 3D model source. Not imported.

No model, texture, animation or plugin from these sources is shipped or loaded.
The full table, including the previously reviewed KayKit, Quaternius Modular
Weapons, Quaternius animation/character packs and Phantom Camera, is
`prototypes/m17/results/godot/m41c-asset-review.md`. The supplementary
`m41c-model-lineup.png` and `m41c-model-pickaxe.png` are renders of the
in-house geometry, not external assets.

## Audio, models, plugins
- **Audio**: none.
- **3D models / creature assets**: none (all geometry is generated by the chunk
  mesher).
- **Plugins / engine extensions**: none. The project is plain Godot 4.7.2; Zylann's
  `godot_voxel` extension was evaluated and rejected during preflight (see
  `prototypes/m17/results/godot-progress.md`), so no GDExtension binary is
  vendored or loaded.

## Engine

- **Godot Engine 4.7.2-stable (mono build, official)** — MIT licence. Installed
  locally at `C:\Godot\Godot_v4.7.2-stable_mono_win64\...`. Not vendored in the
  repository; no engine binary is committed.
