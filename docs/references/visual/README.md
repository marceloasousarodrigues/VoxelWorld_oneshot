# Visual references

These images are art-direction references for future visual work in the Godot project. Read this file and inspect every image in this folder before changing characters, tools, the world, materials, vegetation, buildings, lighting, or atmosphere.

## Priority and intended use

1. **`overall-art-direction.png` — primary target.** This user-supplied composite sets the target style for the character, world textures, vegetation, buildings, tools, lighting, and atmosphere together. Use it to guide shape language, material detail, color, depth, and presentation across the game.
2. **`thirdperson.png` — supporting character/world reference.** This AI-generated concept image was created to extend the primary image’s style into a readable third-person scene. Use it to guide the character silhouette, clothing and pack materials, camera distance, and how the character sits within a richly detailed village environment. The primary composite takes precedence if details differ.
3. **`tool-design.png` — supporting tool-detail reference.** This AI-generated concept image extends the primary image’s tool language with a pickaxe, axe, and pointed spade close-up. Use it to guide silhouettes, haft materials, iron bands, copper rivets, bevels, and forged metal shading. The primary composite takes precedence if details differ.

The generated images are supplemental concepts, not exact project screenshots or approved final models. All reference images are visual guidance only; do not import them as game textures or copy their pixels into runtime assets. Implement the visual language with project-native models, materials, and textures, and validate changes with real Godot runtime captures.

## Existing UI art

The current inventory and hotbar icons are approved. Preserve them during visual work unless the user explicitly requests a change.
